# Referências de componentes

Biblioteca de referências do Grimoire. Tem duas funções: guardar **de onde veio cada ideia** e evitar refazer a mesma pesquisa. Os IDs `REF-NN` são estáveis: as specs citam por eles, e um ID nunca muda de dono. Referências novas entram no fim da lista.

Pesquisa feita em 13/11/2026, em duas rodadas:

1. **Leitura de metadados.** A rodada 1 usou a busca gratuita do 21st, o GitHub e as páginas públicas.
2. **Leitura de código.** A rodada 2 usou o `get_component` do MCP do 21st (plano pago), o código no GitHub (`gh api`), os arquivos de registro da Aceternity e as fontes analisadas a partir do próprio arquivo TTF.

Nada foi instalado. Os arquivos baixados ficaram fora do repositório.

## Legenda

- **Status:**
  - **V**, verificado: o código ou a licença foram lidos.
  - **P**, parcial: parte do código ou da licença ficou sem ler.
  - **U**, não verificado: só a descrição.
- **Código?:**
  - **Sim**: a licença permite copiar código para este repositório (GPL-3.0-or-later), mantendo o aviso no `NOTICE.md`.
  - **Inspiração**: só a ideia ou a técnica, reimplementada do zero.
  - **Não**: nem a ideia vale a pena.
- **Notas (1 a 5):** VI = impacto visual, Re = reuso, Pf = desempenho com muitas instâncias, Cu = personalização, In = facilidade de integração (5 = fácil), A11y = acessibilidade. "—" significa que a referência ainda não foi avaliada pelo código.
- **Faixa:** classifica o uso em card repetido, segundo o código (ver [performance-guidelines.md](performance-guidelines.md)).
  - **F1**: pode em card repetido.
  - **F2**: só no card aberto.
  - **F3**: só no fundo de página.
  - **F4**: só como efeito único.
  - **✗**: não usar.

## Técnicas aprendidas com o código

O resumo vai aqui para não ser preciso reler o código. Cada técnica vem com a referência de onde saiu.

| Técnica                           | Trecho essencial                                                                                                                                                                                                                     | De              | Faixa |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- | ----- |
| Borda desenhada só com máscara    | `padding: var(--bw); mask: linear-gradient(#000 0 0) content-box, linear-gradient(#000 0 0); mask-composite: exclude;`                                                                                                               | REF-16, REF-21  | F1    |
| Volta única pela borda            | borda transparente + `mask-clip: padding-box, border-box; mask-composite: intersect`, com um `::after` em `offset-path: rect(0 auto auto 0 round R)` e `@keyframes { to { offset-distance: 100% } }`, `animation-iteration-count: 1` | REF-34, REF-18  | F4    |
| Giro no compositor                | quadrado de 200% com `conic-gradient(from 0deg, transparent 0 62%, C 82%, transparent 96%)` girando por `transform`                                                                                                                  | REF-17          | F4    |
| Cometa parado                     | o mesmo `conic-gradient` num ângulo fixo, sem animação. Paradas em `color-mix(in srgb, C 4%, transparent)` evitam a faixa cinza                                                                                                      | REF-36          | F1    |
| Brilho que só roda no hover       | `animation-play-state: paused`, que vira `running` em `:hover` e `:focus-visible`                                                                                                                                                    | REF-49          | F1    |
| Entrar e sair de um estado        | `data-active` / `data-fading`, transição de opacidade e saída antes de remover                                                                                                                                                       | REF-35          | F1/F4 |
| Faixa repetida com a cor do token | `background: currentColor; mask: url("data:image/svg+xml,…") repeat-x center / Wpx Hpx`                                                                                                                                              | REF-26          | F1    |
| Vinheta                           | `mask-image: radial-gradient(… circle at center, #000, transparent)`                                                                                                                                                                 | REF-39          | F1/F2 |
| Brilho no texto + fallback        | duas camadas recortadas no texto; em movimento reduzido, `-webkit-text-fill-color: var(--highlight)`                                                                                                                                 | REF-51, REF-53  | F4    |
| Anel de ativação                  | `transform: scale(.6 → 1.6)` + `opacity`, `animationend` remove; 2 ou 3 anéis com atraso de 0,12 s                                                                                                                                   | REF-50, REF-102 | F4    |

**Evitar sempre:**

- `@property` com laço de ângulo, que repinta a cada quadro (REF-35);
- rAF ou timeline por instância (REF-19, REF-37, REF-43, REF-45);
- listeners globais de ponteiro (REF-47);
- `setState` em loop (REF-23, REF-43, REF-44);
- animar `width`/`height` (REF-50);
- blur em card (REF-13, REF-59);
- SMIL, que não respeita o movimento reduzido (REF-85).
